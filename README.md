# 경기창업혁신공간 신규/연장/승급 평가위원회 앱

평가위원회 심사평가를 위한 웹 앱입니다. 별도 설치 없이 브라우저에서 바로 사용합니다.

## 바로 사용하기

👉 **https://edwdyoon.github.io/review-recruitment/**

## 특징

- **위원별 결과 자동 취합** — 위원은 담당자에게 받은 위원명·접속코드로 로그인해 평가하고, 저장할 때마다 결과가 경기도경제과학진흥원 업무용 클라우드(두레이)에 모입니다. 담당자는 비밀번호로 로그인해 전체 결과를 불러와 집계합니다.
- **중계 서버** — 앱과 두레이 사이는 Google Apps Script가 중계합니다. 두레이 인증 토큰과 담당자 비밀번호는 Apps Script 안에만 보관되며, 이 저장소에는 들어 있지 않습니다.
- **본인 결과만 접근** — 위원은 본인 평가만 읽고 쓸 수 있습니다. 신청자의 연락처·이메일은 서버로 보내지 않습니다.
- **글꼴** — Pretendard를 CDN에서 불러오며, 인터넷이 막힌 환경에서는 맑은 고딕으로 표시됩니다.

## 사용 시 유의사항

- 접속코드는 본인만 사용하고 다른 사람과 공유하지 마세요.
- 저장 후 화면 위쪽에 "서버 미전송"이 보이면 "다시 시도"를 누르세요. 점수는 기기에 남아 있어 사라지지 않습니다.
- 공용 PC에서는 평가가 끝난 뒤 반드시 로그아웃하세요.
- 심사 종료 후 담당자는 집계 결과를 엑셀로 내려받아 보관하세요.

```powershell
.\update.ps1
```
