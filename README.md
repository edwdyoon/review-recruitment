# 창업혁신공간 입주/연장 심사위원회 앱

입주기업 심사평가를 위한 웹 앱입니다. 별도 설치 없이 브라우저에서 바로 사용합니다.

## 바로 사용하기

👉 **https://edwdyoon.github.io/review-recruitment/**

## 특징

- **단일 HTML 파일** — 서버·설치·로그인 없이 링크만으로 동작합니다.
- **데이터는 브라우저 안에만** — 접수리스트 엑셀을 업로드해도 파일이 서버로 전송되지 않습니다. 파싱과 저장(`localStorage`) 모두 사용자의 브라우저에서만 이루어집니다.
- **외부 의존성 없음** — 외부 스크립트·폰트·CDN을 불러오지 않습니다.

## 사용 시 유의사항

- 평가 데이터는 **사용하는 기기·브라우저에만** 저장됩니다. 방문 기록 삭제, 시크릿 모드 종료, 다른 기기 접속 시에는 데이터가 남지 않습니다.
- 심사 종료 후에는 결과를 반드시 **파일로 내려받아 보관**하세요.
- 공유 PC에서 사용했다면 종료 전 브라우저 데이터를 정리하는 것을 권장합니다.

## 저장소 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 배포되는 앱 본체 (원본: `04_app/입주기업_심사평가_앱.html`) |
| `update.ps1` | 원본 수정 후 재배포하는 스크립트 |

## 수정 후 재배포

원본 `04_app/입주기업_심사평가_앱.html` 을 수정한 뒤, 이 폴더에서 실행합니다.

```powershell
.\update.ps1
```

푸시 후 1~2분 내에 위 주소에 반영됩니다.
